# Ward 42 Fix-It

## Overview

Ward 42 Fix-It is a Progressive Web Application developed using Flask.

The application allows residents to:

- Report community faults
- Upload evidence photographs
- Track report status

Coordinators can:

- Login securely
- Manage reports
- Update statuses
- View dashboard statistics

## Features

- Fault reporting
- Status tracking
- Image uploads
- Dashboard analytics
- Progressive Web App support
- Offline functionality
- Security controls

## Installation

Install dependencies:

```bash
pip install flask flask-sqlalchemy werkzeug
```

Run the application:

```bash
python app.py
```
